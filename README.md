# Mindustry Drone Swarm Compiler 🚀🤖

Інноваційний Python-компілятор, який перетворює текстові дані у низькорівневий код керування роєм дронів (**Mindustry Logic / mlog**). Проєкт демонструє практичне застосування математичного моделювання, векторної графіки та концепцій **Swarm Robotics** (керування групою автономних одиниць).

> **Note:** Проєкт розроблено та протезовано повністю в мобільному середовищі виконання в межах індивідуальної програми вивчення AI-Driven Development та автоматизації систем.

---

## 🎯 Суть проєкту та Вау-ефект
Програма приймає на вхід будь-який рядок тексту (наприклад, ім'я розробника **"VICTOR"**), розбиває літери на координати у двовимірному просторі за допомогою матричного шрифту, рівномірно розподіляє пул із **100 літаючих юнітів** (тип `@flare` або `@horizon`) і генерує оптимізовану Jump-таблицю для ігрового процесора. 

При вставці згенерованого коду в гру Mindustry, рій дронів синхронно злітається і формує заданий текст на карті.

---

## 🛠 Технологічний стек та інженерні рішення
* **Мова розробки:** Python 3.x (Intermediate/Advanced logic)
* **Алгоритми мапування (Mapping):** Використання оператора залишку від ділення (`idx % num_points`) для автоматичного ущільнення та рівномірного розподілу юнітів по контуру літер, якщо точок у слові менше, ніж роботів у рою.
* **Prompt Engineering у коді:** Проєктування логіки, яка автоматично генерує чистий синтаксичний код для іншої платформи (Mindustry), враховуючи специфіку низькорівневих команд.
* **Захист від збоїв (Fault Tolerance):** Інтегровано перевірки на `null`-юніти (якщо на карті ще немає збудованих БПЛА) та сенсори стану `@dead`, що захищає програму від «зависання» мікропроцесора при знищенні техніки.

## 📊 Структура згенерованого mlog-коду
Програма автоматично збирає логічний ланцюжок:
1. **Прив'язка та валідація:** `ubind` -> Перевірка на існування -> Перевірка на працездатність.
2. **Індексація:** Визначення унікального `target_id` для кожного з 100 юнітів.
3. **Jump-Таблиця:** Розгалуження на 400+ ліній для індивідуального призначення координат $(X, Y)$ відносно позиції процесора `@thisx` / `@thisy`.
4. **Команда руху:** Виклик уніфікованої інструкції `ucontrol move`.

## 💻 Як запустити проєкт
1. Запустіть файл `main.py` у будь-якому Python-середовищі (наприклад, Google Colab чи Replit).
2. Скопіюйте згенерований текстовий лог із консолі.
3. У грі **Mindustry** збудуйте **Гіперпроцесор (Hyper Processor)**.
4. Відкрийте інтерфейс процесора, натисніть **"Edit" -> "Import from clipboard"**.
5. Підведіть енергію до процесора та спостерігайте за збором рою юнітів.
